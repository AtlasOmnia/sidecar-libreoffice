# Sidecar for LibreOffice 0.5.1 — consolidated backlog

Status: planning recommendations, not accepted implementation scope. Snapshot: 2026-11-21. The read-only baseline is `dev/0.5.1`, `4d65e1ecc5eba83470cc7f81f0fa78a8af172b33` (clean when inspected). The two owner-selected headlines are E01 and E02; their designs await spikes D and W.

## How to read this

Each row is one deduplicated concern. **Type** is bug, security, UX, test or docs, not a claim that a security exploit exists. **Priority**: P1 = ship/gate with the headlines; P2 = useful bounded follow-up; P3 = separate future work or deliberately rejected direction. No new release-blocking exploit was established by this planning exercise. **Size**: S = a small bounded change/check; M = several interacting changes or a native test session; L = protocol/platform design or external dependency. These are rough planning sizes, not estimates from an implementation spike. **OXT** says whether implementing the item changes the companion extension archive: Yes, No, or Conditional (design-dependent). Even a source-comment change inside the extension changes that archive. Test-only checks do not themselves change it.

Source shorthand: `050/` = `../design-0.5.0/`; `041/` = `../release-0.4.1/`; `WT/` = `/Volumes/Development SSD/Repositories/sidecar-libreoffice-0.5.1/`. Review section/item names are the stable locator; historical code line numbers are not current line numbers. Repeated mentions in fix/integration reports are consolidated under the strongest later disposition. Items closed by later evidence are listed separately below, not counted as open bugs.

## Reconciliation: historical findings that are not still open bugs

- **Non-ASCII HTTP launcher paths:** fixed by fix2, confirmed in both round-3 reviews and `WT/CHANGELOG.md` 0.5.0 Security. Malformed paths now get an unsigned 404 before MAC processing, without a 500/error-log flood or channel damage. Keep this regression in G1. This is not evidence that non-ASCII filesystem/profile paths were tested: exercise accented and non-Latin cache/profile paths in the new native launcher gates (an added 0.5.1 verification requirement, not a historical reproduced filesystem bug).
- **New-chat overlap and stale state:** deterministic local guard/epoch problems were fixed by fix2; only distributed transport uncertainty remains P01.
- **Last-64 and busy prose:** final-local wording commit `797aeb5` scoped protocol/CHANGELOG deduplication, distinguished first busy from retry busy, and stated per-page rather than transactional New chat. Do not reopen those exact fixed sentences. Remaining page text is P02.
- **Long-poll race, log barrier, hello-flood channel eviction, noisy INFO polls, unsigned busy/5xx/displaced-channel panel text, Windows CRLF sum fixtures, and malformed path exceptions:** fixed across fix1–fix3. Sources: `050/fix1/P/REPORT.md` Items, `050/integration/FIX1-INTEGRATION.md` Cross-requests, `050/fix2/REPORT.md` Additional scope, `050/fix3/REPORT.md` What changed, and round-4 dispositions. Retain regressions, not duplicate work items.
- **Linux listener-before-Stop short-budget failure and cumulative Stop/listener budgets:** fixed with causal evidence and round-4 review. The independent shared-fake-clock millisecond class remains T01; do not combine them as one flake.
- **0.4.1 event-loop immediate-rebind grace, catalog old-tag blocker, old poll-minimum claim, close docstring sequencing and stale ownership comments:** later code/wording resolves the principal defects (0.5.0 CHANGELOG Security/0.4.1 Fixed; final-local Commits). Remaining exact-address comment/prose is E16/D04. No retrospective 0.4.1 native/model passes are claimed.
- **Lane cross-requests:** integration §2 resolves the sanitizer alignment/list-start option, raw-HTML escaping, theme script name, chat-label format, strict sequence numbers/signed malformed-ID handling, route ordering/refusals, helper manifest entry, server banner, Tools menu semantics, memory/profile-size disclosures, reconnect identity and version-mismatch text. The only still-relevant external catalog reconciliation is D02. Do not resurrect lane-stage missing files or obsolete hashes.
- **Native final pair and Safari basic smoke:** `050/acceptance/FINAL-LOCAL-GATES.md` records final macOS/ATLAS/Safari runs. The released CHANGELOG additionally records an owner-reported real-gateway Calc write/read/Stop/quit and Extension Manager replacement. These supersede the older blanket “never run natively/live/upgrade” statements, but leave the specific V01–V17 evidence gaps above.
- **Fallback and R18:** despite earlier scope-cut prose, owner D1 moved tab fallback into 0.5.0 and D4 included challenge-response. They shipped; they are not new 0.5.1 features.
- **Same-user credential access, loopback port takeover, browser-vendor networking/history/managed extensions, OS/filesystem stall limits and the unload fence exception** remain accepted/disclosed trust boundaries.
